# Newtab

Minimal extension with no dependencies

## Features 
- Bookmarks, including folders
- Digital clock or analog clock
- Default wallpapers and support for custom ones
- All stored in localStorage, no magic permissions asked
- 0 suspicious code, I don't want the data of anyone
