NewTab Pro - Extension Test

This page tests the basic functionality of the NewTab Pro extension.

Manual Tests

  • Load the extension in Chrome by going to chrome://extensions/
  • Enable "Developer mode"
  • Click "Load unpacked" and select this directory
  • Open a new tab to see the NewTab Pro interface
  • Test the settings modal by clicking the gear icon
  • Test bookmark loading (requires bookmark permissions)
  • Test search functionality
  • Test wallpaper changes
  • Test language switching
